How the Summation Assistant files & finds email

This page covers the four things most people use the Assistant for day-to-day: filing an email to a project, how that filing actually reaches SharePoint, what happens to things you send, and how to search everything that's ever been filed.

The Email Management folders

Master Email Management — the parent folder for everything below, in your Inbox
Emails Yet to Label — your own parking spot. Nothing automatic happens here until you move something out.
Emails Awaiting Sync — labelled and ready. The automatic pass files anything it finds here.
Synced Emails — already filed to SharePoint. Kept here so you can still find it in Outlook.

Three ways to label an email

File Email

Pick one or more emails, choose a project, done. Good for a handful of emails right now.

Batch File Folder

Work through every email in a folder at once, assigning a project to each row. Good for clearing a whole backlog in one sitting.

While composing

Writing a reply or new email can show a banner offering to tag it there and then — entirely optional, never blocks sending.

Recommended habit, if you're short on time

Don't stop to decide right now — just drag the email into Emails Yet to Label as it comes in. Then, every so often, open Batch File Folder on that same folder and work through everything you've parked there in one go.

Smart project suggestions

Wherever you're asked to pick a project — File Email, Batch File Folder, or the compose-time banner — look for Suggested options above the regular list. They're worked out from three things: whether this exact conversation has already been filed somewhere, whether you've emailed these same people before on a project, and whether the wording looks similar to other emails already filed there. One click on a suggestion beats searching, and it gets better over time as more gets filed.

Overview

Every email you file ends up as a .eml file inside that project's Emails folder on SharePoint. Two things get it there: you tagging the email in Outlook (manual), and a background process that actually moves it (automatic). You never have to trigger that second part yourself anymore — it just runs.

1. File Email You do this

Button: File Email

  1. Select one email, or multiple emails, in your inbox (or open one).
  2. Click File Email in the Summation Assistant pane.
  3. Choose Sustainability or Energy, then search for the project folder and select it.
  4. Click Add Category & Stage for Filing.

That's it on your end. This tags the email with the project as an Outlook category and moves it into the Master Email Management → Emails Awaiting Sync folder in your Inbox. It does not file it to SharePoint immediately — see the next section.

Filing multiple emails at once? Select them all first (Ctrl/Shift-click in the list), then click File Email once.

2. Automatic filing Happens on its own

No button — runs in the background, about every 5 minutes

A background process (not part of the Outlook pane itself) checks every staff mailbox's Master Email Management → Emails Awaiting Sync folder on a timer. For each email it finds there, it:

  1. Works out the project from the category you added.
  2. Saves a copy of the email into that project's Emails folder on SharePoint.
  3. Moves the original out of Emails Awaiting Sync into Master Email Management → Emails Awaiting Sync → Synced Emails — so your inbox stays clean and you can still find it if you need to.

This usually takes a few minutes from when you click File Email. There's nothing to check or trigger — if it's not in Synced Emails yet, it just hasn't run its next pass.

Didn't pick a project when filing? The email just waits harmlessly in Emails Awaiting Sync until it's tagged with one. Nothing is filed incorrectly, and nothing is lost. Want to come back to an email later instead of deciding now? Drag it into Master Email Management → Emails Yet to Label — that folder is just for your own use, nothing automatic happens to what's in it until you manually file it or use Batch File.
Tagged an email with a project somewhere else — e.g. via the compose-time Categorise Conversation, or by hand — and it's still just sitting in your Inbox or Sent Items instead of Emails Awaiting Sync? Click Mailbox Sync in the Assistant pane: it searches your whole Inbox (including subfolders) and Sent Items for anything already labelled this way and moves it into Emails Awaiting Sync for you, so the automatic pass above can pick it up.

3. Categorise while composing Optional, never blocks sending

A banner that can appear while you're writing a new email, reply, or forward

  1. While composing, you may see a File this email to a project banner near the top of the message. It's entirely optional — ignore it and send normally if you don't want to deal with it right now.
  2. Click Choose project on the banner to open the picker in the Assistant pane, then search for the project (or click ← Back to email to close the picker and keep composing — nothing is tagged if you do this).
  3. Pick a project. If you're replying or forwarding, you'll see two options: Categorise Conversation (tags your reply, plus every message this conversation has sitting in your Inbox right now — the picker shows how many it found) or Categorise Reply Only (just your reply). A brand-new email just has one Categorise option.
  4. That's it — this only tags the email(s) with the project, it doesn't move anything, and sending is never blocked or delayed by any of this. Your own sent reply gets filed automatically from there, the same way File Email's does. Any other tagged conversation message stays right where it is in your Inbox until you move it into Master Email Management → Emails Awaiting Sync yourself, same as any other email you want filed manually.
There's no prompt at the actual moment you click Send — if you'd rather tag an email after the fact instead of while composing, use File Email (section 1) on the sent copy, or just drag it into Emails Yet to Label for later.

4. Email Search Search everything that's been filed

Button: Email Search

  1. Click Email Search in the Summation Assistant pane — it opens in your web browser.
  2. Sign in with your Summation account the first time you use it.
  3. Use the filters on the left (project, date, sender, label match/mismatch, etc.) and the search box to find emails across every project, not just ones you personally filed.
  4. Click a result to preview it on the right, or use Open in Outlook to download the original file.

This searches every email filed into a project's folder on SharePoint, by anyone, going back to when indexing began — it's a lot more useful than digging through folders by hand, especially for older or archived projects.

All Summation staff can search all projects — there's no per-project access restriction on search.

Other actions in the Assistant

A few other buttons exist for less frequent, project-admin tasks:

  1. New BD project — allocates the next project number, files the current email into it, and creates the project's mailbox.
  2. Change BD to Active project / Convert Active to Archive — moves a project folder between the Active and Archive libraries.
  3. Search Shared Mailbox Online Legacy — opens an existing project mailbox directly in Outlook Web. Kept for now as project mailboxes are phased out in favour of filing straight to SharePoint; prefer Email Search above for finding emails.
