How the Summation Assistant files & finds email

This page covers the four things most people use the Assistant for day-to-day: filing an email to a project, how that filing actually reaches SharePoint, what happens to things you send, and how to search everything that's ever been filed.

Overview

Every email you file ends up as a .eml file inside that project's Emails folder on SharePoint. Two things get it there: you tagging the email in Outlook (manual), and a background process that actually moves it (automatic). You never have to trigger that second part yourself anymore — it just runs.

1. File Email You do this

Button: File Email

  1. Select one email, or multiple emails, in your inbox (or open one).
  2. Click File Email in the Summation Assistant pane.
  3. Choose Sustainability or Energy, then search for the project folder and select it.
  4. Click Add Category & Stage for Filing.

That's it on your end. This tags the email with the project as an Outlook category and moves it into a folder called Emails to File in your Inbox. It does not file it to SharePoint immediately — see the next section.

Filing multiple emails at once? Select them all first (Ctrl/Shift-click in the list), then click File Email once.

2. Automatic filing Happens on its own

No button — runs in the background, about every 5 minutes

A background process (not part of the Outlook pane itself) checks every staff mailbox's Emails to File folder on a timer. For each email it finds there, it:

  1. Works out the project from the category you added.
  2. Saves a copy of the email into that project's Emails folder on SharePoint.
  3. Moves the original out of your Inbox into a Filed folder — so your inbox stays clean and you can still find it if you need to.

This usually takes a few minutes from when you click File Email. There's nothing to check or trigger — if it's not in Filed yet, it just hasn't run its next pass.

Didn't pick a project when filing? The email just waits harmlessly in Emails to File until it's tagged with one. Nothing is filed incorrectly, and nothing is lost.

3. File on Send You choose, every time

Pops up automatically whenever you click Send

  1. Click Send on any email as normal — a small window pops up before it actually sends, asking you to file it.
  2. Search for the project (or click ← Back to email to cancel the send entirely and go back to your draft — nothing is sent or filed if you do this).
  3. Pick a project. If you're replying or forwarding, you'll see two options: Save Both (files the original email you're replying to, as well as your reply) or Reply Only (just your reply). A brand-new email just has one Save option.
  4. That's it — the window closes and your email sends. Filing continues in the background, the same way File Email's does.
This pops up on every send, including personal/non-project emails — there's currently no "send without filing" option, only pick a project or cancel the send. If that turns out to be too disruptive day-to-day, let us know.

4. Email Search Search everything that's been filed

Button: Email Search

  1. Click Email Search in the Summation Assistant pane — it opens in your web browser.
  2. Sign in with your Summation account the first time you use it.
  3. Use the filters on the left (project, date, sender, label match/mismatch, etc.) and the search box to find emails across every project, not just ones you personally filed.
  4. Click a result to preview it on the right, or use Open in Outlook to download the original file.

This searches every email filed into a project's folder on SharePoint, by anyone, going back to when indexing began — it's a lot more useful than digging through folders by hand, especially for older or archived projects.

All Summation staff can search all projects — there's no per-project access restriction on search.

Other actions in the Assistant

A few other buttons exist for less frequent, project-admin tasks:

  1. New BD project — allocates the next project number, files the current email into it, and creates the project's mailbox.
  2. Change BD to Active project / Convert Active to Archive — moves a project folder between the Active and Archive libraries.
  3. Search Shared Mailbox Online Legacy — opens an existing project mailbox directly in Outlook Web. Kept for now as project mailboxes are phased out in favour of filing straight to SharePoint; prefer Email Search above for finding emails.
