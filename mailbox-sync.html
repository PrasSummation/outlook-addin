Mailbox Sync

Please sign in to run Mailbox Sync.

Finds emails anywhere in your Inbox (including its subfolders) or Sent Items that already have a project category applied, but were never moved into Master Email Management → Emails Awaiting Sync for automatic filing — e.g. anything tagged via Categorise Reply/Categorise Conversation on send, or labelled some other way and left in place.

  • Every match gets moved into Emails Awaiting Sync, same as File Email does — nothing is filed to SharePoint directly by this tool, the existing automatic sync picks it up from there.
  • The Master Email Management folder itself (Emails Yet to Label / Emails Awaiting Sync / Synced Emails) is never scanned — nothing already staged or already filed gets touched.
  • Anything already tagged Filed is left alone, even if it also carries a project category.
